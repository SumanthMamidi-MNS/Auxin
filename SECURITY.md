# Security Policy — Auxin

We take security seriously. If you discover a vulnerability, please report it to us confidentially so that we can patch it before public disclosure.

---

## Reporting a Vulnerability

Do **not** open a public GitHub issue for security bugs. Instead, email security reports to Sumanth Mamidi at `sumanthmamidi74@gmail.com`.

Include:
- Details of the vulnerability.
- Steps to reproduce (proof of concept).
- Potential impact.

We will acknowledge receipt within 48 hours and work on a patch as quickly as possible.

## Supported Versions

Only the current main release branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 3.0.x   | :white_check_mark: |
| < 3.0   | :x:                |
